# Vinta

Vinta is an open-source, highly customizable Dynamic Island for PC. Built with Go and Svelte, it brings a beautiful, fluid floating widget to your desktop.

## Features
- **Frameless & Transparent:** Seamlessly blends into your desktop environment.
- **Fluid Animations:** Powered by Svelte for 60fps micro-animations.
- **System Integrations:** Clock, Calendar, Spotify, and Notifications (coming soon).
