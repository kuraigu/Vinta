# Support Guide

Need help with Vinta? Here are the best ways to get support and connect with the community.

## Documentation

Before asking a question, check our documentation:

- [README](README.md): Project overview, features, and setup instructions.
- [Contributing Guide](CONTRIBUTING.md): Guide on building, running, and creating components.
- [Design Guide](docs/DESIGN.md): Visual standards and theme variables.

## Asking Questions and Getting Help

If you have a question or need setup help:

1. Search open and closed [GitHub Issues](https://github.com/kuraigu/Vinta/issues) to see if your question has already been answered.
2. Start a new [GitHub Discussion](https://github.com/kuraigu/Vinta/discussions) or open an issue labeled `question`.

## Reporting Bugs

If you encounter a bug or unexpected behavior:

1. Check open issues to avoid duplicates.
2. Open a new GitHub Issue using the bug report format.
3. Include your operating system version, reproduction steps, and screenshots if possible.
