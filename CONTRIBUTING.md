# Contributing to Vinta

First off, thanks for taking the time to contribute! 

## Development Setup
1. Fork and clone the repository.
2. Ensure you have Go, Node.js, and the Wails CLI installed.
3. Run `wails dev` to start the development server. The backend will recompile on Go changes, and the frontend will hot-reload on Svelte changes.

## Pull Requests
- Please create a new branch for your feature or bugfix.
- Ensure your code follows the existing style.
- Reference any open issues your PR resolves.
