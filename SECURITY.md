# Security Policy

The Vinta team takes the security of our application and users seriously. Thank you for helping keep Vinta safe!

## Supported Versions

Security updates are provided for the following versions:

| Version | Supported |
| :--- | :--- |
| Latest Main / Release | Yes |
| Older Pre-Releases | No |

## Reporting a Vulnerability

If you discover a security vulnerability in Vinta, please report it privately:

1. **Do not** open a public GitHub issue for security vulnerabilities.
2. Contact project lead Innoh Reloza (@kuraigu) via GitHub Security Advisory or direct message.
3. Include details on the vulnerability, steps to reproduce, and potential impact.

## Response Commitment

- We will acknowledge receipt of your report within 48 hours.
- We will provide an estimated timeline for addressing the vulnerability.
- Once fixed, we will publish an update and credit you in our security advisories.
